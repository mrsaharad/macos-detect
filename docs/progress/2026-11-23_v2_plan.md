## ทดสอบการป้องกันตัวเอง (23 พ.ย. 2569 18:45 น., daemon v2 ติดตั้งด้วย deploy/install_daemon.sh)
daemon ทำงานด้วย root (Python 3.9 ของระบบ + eslogger เป็นลูก), Full Disk Access ผ่าน, เก็บ event ทุกชนิดรวม close/truncate/setextattr
ลองโจมตีตัวระบบด้วยสิทธิ์ผู้ใช้ทั่วไป (ผู้ใช้เป็น admin แต่ไม่ใช้ sudo) — **ถูกปฏิเสธทั้ง 6 ทาง**:
| วิธี | ผล |
|---|---|
| kill -9 collector | operation not permitted |
| kill -9 eslogger | operation not permitted |
| ลบ alert ในฐานข้อมูล | attempt to write a readonly database |
| แก้ไฟล์กฎ | permission denied |
| ลบไฟล์กฎ | permission denied |
| launchctl bootout daemon | Operation not permitted |
ยังเหลือทดสอบ: KeepAlive (ให้ผู้ใช้ `sudo kill -9` แล้วดูว่า launchd เปิดใหม่และ Dashboard แสดง heartbeat ต่อ)
ข้อจำกัด: ผู้โจมตีที่ได้ root ยังปิดได้ (อยู่นอก threat model)
