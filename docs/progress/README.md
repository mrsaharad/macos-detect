# docs/progress — บันทึกความคืบหน้าที่ใช้ร่วมกันระหว่างแชท

โฟลเดอร์นี้ใช้ส่งต่อความคืบหน้าระหว่างแชทที่ทำงานคนละส่วนของโปรเจกต์

| แชท | หน้าที่ | ไฟล์ที่เขียน |
|---|---|---|
| Claude Code (แชทโค้ด) | ระบบ, กฎ, การทดลอง, ผลวัด | `YYYY-MM-DD_code.md` |
| แชท Word | เล่มโครงงาน (.docx) | `YYYY-MM-DD_word.md` (ถ้ามี) |

ข้อตกลง
- 1 ไฟล์ต่อวันต่อแชท ชื่อขึ้นต้นด้วยวันที่ เรียงตามเวลาเองได้
- ก่อนเริ่มงาน ให้อ่านไฟล์ล่าสุดของอีกแชทก่อน
- ตัวเลขที่จะนำไปใส่เล่มต้องระบุว่า "ยืนยันแล้ว" หรือ "ชั่วคราว"
- ไฟล์ที่นี่อ่านอย่างเดียวสำหรับอีกแชท ถ้าจะแก้ข้อมูลของอีกฝั่ง ให้เขียนลงไฟล์ของตัวเองแทน
