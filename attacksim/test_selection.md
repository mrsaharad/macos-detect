# การคัดเลือก Atomic test (ตรวจ 22 พ.ย. 2026, atomics ชุดที่ติดตั้งวันเดียวกัน)

ตรวจคำสั่งและ cleanup ของทุก test ใน `plan.txt` ด้วย `Invoke-AtomicTest <T> -ShowDetails` ก่อนรัน
สภาพเครื่องตอนตรวจ: ใช้ zsh, ไม่มี `~/.bash_history`, `~/.bashrc`, `~/.bash_profile`, ไม่มี crontab

| แผนเดิม | ปัญหา | ทางแก้ |
|---|---|---|
| T1562.001 | ใน ATT&CK v19 ย้ายไปเป็น **T1685** Disable or Modify Tools | ใช้ T1685-12 (Disable macOS Gatekeeper) + แก้แท็กของ MD-0020 |
| T1562.004 | ย้ายไปเป็น **T1686** Disable or Modify System Firewall และ**ไม่มี test สำหรับ macOS** | ทดสอบด้วยมือแทน (ถ้าอนุมัติ) + แก้แท็กของ MD-0021 |
| T1059.006 | ไม่มี test สำหรับ macOS | ทดสอบด้วยมือแทน หรือตัดออก |

## การตัดสินใจ (ผู้ทำโครงงาน, 22 พ.ย. 2026)
- รัน test ระดับเขียวและเหลืองทั้งหมด ไม่รันระดับแดง
- T1686 และ T1059.006 ทดสอบด้วยมือแทน (`attacksim/manual_tests.sh`)
- test ที่ Atomic กำหนดว่าต้องใช้สิทธิ์ root (เลขที่มี `!` ใน plan.txt) รันผ่าน `sudo pwsh`
  เพราะถ้า PowerShell ไม่ได้รันเป็น root Invoke-AtomicTest จะข้าม test นั้นไป
  ได้แก่ T1087.001-2, T1016-8, T1543.001-1, T1543.001-3, T1543.004-1, T1685-12
